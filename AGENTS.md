# Instructions pour les agents IA

## Dossier images_commerces — NE PAS MODIFIER

Le dossier `images_commerces/` contient 1463 images de commerces montpelliérains.

**Ne jamais :**
- Supprimer ce dossier ou son contenu
- Vider les fichiers qu'il contient
- Inclure ce dossier dans un commit qui le modifie ou le supprime
- Faire un `git add .` sans vérifier que ce dossier est intact

**Toujours :**
- Faire un `git pull` avant tout commit/push pour avoir la version à jour du dossier
- Ignorer ce dossier dans le cadre de refactorisations ou nettoyages de code
